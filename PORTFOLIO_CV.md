## LinkedIn/project summary

Developed a credit-risk portfolio case study using the UCI Default of Credit Card Clients dataset. The project focuses on Probability of Default rather than binary prediction alone, compares an interpretable baseline with a nonlinear challenger, evaluates calibration and threshold trade-offs, and translates model output into business-facing risk segments. The repository includes reproducible code, tests, a model card and interview-ready documentation.
